Website Analytics

browserlab.io does not load Google Analytics or set analytics cookies. There is no website analytics consent prompt. We use Google Search Console to review aggregate search impressions and clicks, and separate Chrome Web Store reports to review extension store visits and installations. Store links may include campaign parameters identifying the website page. These parameters do not include transcript text or a visitor identifier.

The transcript cleaner processes your text in your browser. We do not send pasted transcripts or text entered into website tools to an analytics service. Website reporting is separate from the extensions and the Chrome Web Store's own analytics.

Browser Storage and Cookies

The website no longer saves an analytics preference or landing-page record. When you visit an updated page, a local cleanup script removes the settings and cookies created by the previous website analytics setup. It does not send data or change other browser storage.
